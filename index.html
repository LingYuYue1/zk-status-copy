怎么装
  1. 点上面「下载正则 JSON」，文件会存到手机的下载目录
  2. 酒馆 → 扩展 → 正则（Regex）
  3. 找到底部的 导入 按钮（有的版本叫「Import」）
  4. 选刚下载的那个文件
  5. 它会覆盖同名的「状态栏美化」条目，或者新增一条
  6. 保存，刷新聊天
⚠️ 如果导入后还是显示一堆代码：
检查那条正则的 markdownOnly 是不是 开、promptOnly 是不是 关， 以及替换内容开头有没有 ``` 三引号（不能有）。
这次修了什么
上一版我在替换内容外面加了 ``` 代码围栏（照抄原卡格式）。 结果酒馆的 markdown 引擎把它当代码块，HTML 被转义，显示成代码。

这一版去掉了围栏，裸 HTML 会被原样透传，浏览器就能渲染成 UI。 已经用真实酒馆引擎验证：不再出现 pre 代码块，.zk 根节点正常生成。
